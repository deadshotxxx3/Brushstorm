# Brushstorm — фронтенд

Статичный макет интерфейса игры: экран входа (создание комнаты и вход по коду) и экран лобби.
Пока без JavaScript, данные на странице выдуманные.

## Файлы

- `index.html` — разметка страницы
- `style.css` — стили
- `logo.svg` — логотип в шапке страницы
- `favicon.svg` — иконка вкладки браузера

## Как открыть

Открыть `index.html` в браузере двойным кликом, сервер не нужен.
